In this project:
I apply mathematical concepts, 
work with Python modules, 
parse command-line arguments, 
calculate financial parameters, 
and improve my command-line interface (CLI) skills.

Этот проект поможет вам разобраться в кредитах и ​​ипотеке с помощью удобного калькулятора.
Передаем параметры: как сумма кредита, процентная ставка и условия оплаты. 
Программа рассчитает ключевые финансовые параметры. 
Вы можете определить свой ежемесячный платеж, общую сумму выплачиваемых процентов или сумму кредита, которую вы можете себе позволить. 
Кроме того, это отличный проект для использования интерфейса командной строки.
